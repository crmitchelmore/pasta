# Changelog

All notable changes to Pasta will be documented in this file.

## [1.0.0] - 2026-05-14

First stable release. Pasta moves out of preview status with a hardened
clipboard pipeline, FTS5 search, and a configurable detection engine.

### Added
- **Pinned items** — Pin clipboard entries to the top with `⌘⇧P`. Optional
  auto-injected Pinned section in Quick Search (gated behind a setting).
- **Snippets** — Saved clips with dynamic placeholders (`{date}`, `{time}`,
  `{datetime}`, `{clipboard}`, `{clipboard:N}`, `{cursor}`, `{uuid}`),
  JSON import/export, and CRUD UI under Settings → Snippets.
- **Multi-select copy** — Select multiple entries and copy them as one.
- **Paste as plain text** — `⇧Enter` / `⌥Enter` strips formatting on paste.
- **Open URL entries** — `⌘O` opens a URL entry in the default browser.
- **Clear-all history** — `⌃⇧X` with confirmation.
- **Keyboard content-type filter** — `⌘P` cycles content type filters.
- **Detection rules engine** — Per-detector strictness profiles
  (`Lax` / `Medium` / `Strict`), advanced regex overrides with performance
  ratings, and user-defined custom detectors.
- **New detectors** — MAC addresses, credit cards (with masked preview),
  IBANs, and CSS/hex/rgb colors with swatch previews.
- **Privacy: transient pasteboard** — Honors
  `org.nspasteboard.{Transient,Concealed,AutoGenerated}Type`,
  `com.apple.is-sensitive`, and common password manager identifiers so
  password manager output is never recorded. User-toggleable in Settings.
- **Onboarding walkthrough** — Full feature tour with replay from settings.
- **Diagnostics opt-in** — Sentry crash reporting is now strictly opt-in
  via Settings → General → Diagnostics. Off by default; clipboard
  contents are never transmitted.
- **CI launch smoke test** — Builds, signs, and launches a release-shaped
  bundle on every PR; entitlements are statically validated.

### Changed
- **FTS5 ranking** — Combines BM25 with a recency penalty and folds exact
  equality into the score.
- **Two-stage FTS5 query** — Skips BLOB hydration for non-winning rows,
  cutting search latency on large databases.
- **UTF-16-aligned match ranges** — Eliminates highlight off-by-one on
  multibyte content.
- **Detector cost** — Skips code-language scoring on prose paragraphs.
- **Memory** — Image-hash and preview caches optimized.
- **Incremental refresh** — Entries refresh incrementally after inserts
  instead of refetching the full list.
- **Off-main work** — Quick Search, panel search/filtering, screenshot
  processing, and syntax highlighting all moved off the main thread.
- **Codebase split** — Large files broken into focused extensions/files
  (`PastaApp`, `AppDelegate`, `DatabaseManager`, `ContentTypeDetector`,
  `PreviewPanelView`, `QuickSearchView`, `ImportService`, `SettingsView`)
  for maintainability.

### Fixed
- Stale preload cache that surfaced outdated entries after data changes.
- Window not appearing when `Cmd+Tab` returned to the app after closing.
- Hangs on large metadata payloads and on the API-key list.
- `try!` fallbacks in `BackgroundService` replaced with explicit error
  paths (with optional Sentry capture when opted in).

### Documentation
- Privacy claims in `README.md` and `SECURITY.md` reconciled with
  reality (Sentry is opt-in, CloudKit is opt-in, Sparkle for updates).
- Added `LICENSE` (MIT).
- `SECURITY.md` placeholders, supported-version table, and database path
  corrected.

## [0.7.0] - 2026-01-28

### Added
- **Command Mode** - Type `!` in quick search to enter command mode with 40+ commands:
  - **Clear commands**: `!clear 10 mins`, `!clear 1 hour`, `!clear 1 day`, `!clear <n> mins/hours/days`, `!clear all`
  - **Monitoring**: `!pause`, `!resume` clipboard monitoring
  - **Settings toggles**: `!sounds on/off`, `!notifications on/off`, `!images on/off`, `!dedupe on/off`, `!extract on/off`, `!skip-api-keys on/off`
  - **Theme control**: `!theme light`, `!theme dark`, `!theme system`
  - **Navigation**: `!settings`, `!updates`, `!release notes`, `!quit`
  - **Quick filters**: `!urls`, `!emails`, `!images`, `!text`, `!code`, `!paths`
  - **Help**: `!help` shows all available commands
- Confirmation dialog for destructive commands (`!clear all`)
- Success feedback after command execution
- Menu bar quick actions: "Clear History" submenu with "Last 10 Minutes" and "Last Hour" options

### Fixed
- Fixed window not appearing when Cmd+Tab to app after closing window (window reference was stale)
